# Red: 독립 리뷰 권고 반영 (feat/share-page, f32af9a 위)

테스트만 바꾸고 구현은 f32af9a 그대로 둔 상태에서 실행했다(2026-11-17).

## 1. 단위
바꾼 기대: 형식이 다른 page도 링크는 201로 담고 "담았어요. 다만 페이지 정보는 읽지 못했어요. …" 메시지(권고 1),
스크립트가 서버가 읽는 메타 일곱 키·상품 JSON-LD만 보내고 ld+json이 아닌 스크립트의 글을 읽지 않음(권고 3),
대표 주소 호스트가 링크와 같으면 같은 페이지(권고 6, 서명이 {url, canonical}로 바뀌어 기존 같은 페이지 네 경우도 실패),
안내 문구(설정 → 앱 → 단축어 → 고급, 이전 iOS, ‘입력이 없는 경우’ → ‘중단’, 처음 실행의 사이트별 ‘허용’)(권고 7), API 문서에서 invalid_page 제거.

## 3. 실제 HTTP·브라우저
HTTP("형식이 다른 page여도 링크는 201…")와 브라우저(안내 문구)의 바뀐 기대는 위 DB 단계에서 멈춰 따로 Red를 보지 못했다.
같은 동작은 1의 처리기·안내 단위 Red가 확인한다.
