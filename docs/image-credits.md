# 목업 이미지

아래 Unsplash 이미지를 UI 검토용 예시 상품에 사용했다. 상품명, 쇼핑몰과 가격은 별도 예시이며 사진에 등장하는 실제 제품의 판매 정보를 나타내지 않는다. 앱은 외부 이미지 요청 없이 `public/images`의 사본을 표시한다.

Pretendard 1.3.9의 웹폰트 사본을 사용했다. 폰트의 SIL Open Font License는 `public/fonts/OFL.txt`에 있다.
